# Source art

Original artwork the game is built from. The game never loads this folder and it is not deployed.

- `swiftee-assets/` — Swiftee's character pack. `node tools/build-swiftee.cjs` reads its manifest and sprite sheets and writes the sheets the lesson plays to `assets/swiftee/` and their table to `src/lesson/swiftee-sheets.js`.
- `swiftee-flying-sheet.png` — the original flying sheet that `assets/swiftee/swiftee_flying@1x.webp` was cut from.
