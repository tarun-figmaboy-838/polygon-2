Game ↔ Lesson Kit

The screens before and after the learning section, in order, as they run in Polygon Adventure. The game opens the experience and holds still at its first problem; Swiftee flies in and sends the learner to the lesson; snow carries the game away onto it. After the lesson the game comes back by itself, and Swiftee meets Momo at the same kind of problem.

How to build it into another game, the files, the messages and the timings: README.md in this folder.
